# Portfólio Pessoal

Portfólio pessoal desenvolvido em **React**, apresentando meus projetos, habilidades e informações de contato.  
Design moderno, responsivo e fácil de navegar, ideal para mostrar meu trabalho como desenvolvedor web.

## Tecnologias
- React
- HTML5 / CSS3
- JavaScript (ES6+)

## Funcionalidades
- Seção "Sobre mim"
- Meus projetos com links
- Habilidades e experiências
- Contato direto via links sociais

## Como rodar localmente
```bash
git clone https://github.com/goncallvescarllos/portifolio.git
cd portifolio
npm install
npm run dev
